# 🛍️ Simple Store

یک فروشگاه اینترنتی نمونه ساخته‌شده با **React**، **TypeScript** و **Tailwind CSS**.

## 🚀 دموی زنده

🔗 **[مشاهده پروژه](https://chifuyu1386.github.io/simple.store/)**

## 📖 درباره پروژه

Simple Store یک پروژه‌ی پورتفولیو است که یک تجربه‌ی خرید واقعی را شبیه‌سازی می‌کند. امکانات اصلی:

- لیست محصولات با جستجو، فیلتر و مرتب‌سازی
- صفحه‌ی جزئیات محصول با گالری و نظرات
- سبد خرید با ماندگاری در `localStorage`
- تسویه‌حساب چند مرحله‌ای
- ورود کاربر با JWT
- طراحی واکنش‌گرا با پشتیبانی کامل RTL

## 🛠️ تکنولوژی‌ها

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- React Router v6
- Context API + useReducer
- DummyJSON (API)
